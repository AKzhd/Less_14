# Order Service

Сервис расчёта стоимости заказа.

## Правила расчёта

1. Сумма всех позиций: `price * quantity`.
2. Скидка по типу клиента:
   - `VIP` — 10%
   - `NEW` — 5%
3. Если суммарное количество единиц товара больше 10 — дополнительная скидка 1%.
4. Если итоговая сумма больше 1000 — вычитается 50.
